Overview

A real-time audio plugin that uses machine learning for phonetic classification to selectively apply corrective DSP to sibilant frequencies. Created as part of a Master's Dissertation project at Queen Mary University of London (QMUL).

Current Status: v1.0 (Testing & Academic Documentation)

Quick Links

  • Source Code on GitHub

Information

The main idea behind this project is to use machine learning classification to detect phonetics. Phonetics are the smallest level of spoken language which togeather form letters then words. To increase speed we perform waveform detection instead of parsing the audio into a different format, meaning our input was 512 audio samples. We would then colapse this into a our final output layer or classes [51, 9, 5, 3, or 2]
