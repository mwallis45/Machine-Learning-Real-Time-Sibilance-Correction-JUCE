Overview

This project looked at implementing a real time phonetic detection model to apply vocal correction DSP. This looked at a simple NN with a 512 window size with a step size of 128 samples, going down to a final classification of classes 51, 9, 5, 3 or 2. For full information, check the full report document but bare in mind that it is not peer reviewed and has places for improvement

Created at Queen Mary University of London, for the final disertation Module.
